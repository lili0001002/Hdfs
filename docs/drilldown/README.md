## 连接和接手验证

现有 `.claude` SessionStart hooks 负责接入 Tailscale 并配置 `win-tailnet`；不要无故替换它们。
SSH 别名默认 `win-tailnet`，可用私密环境变量 `DRILLDOWN_SSH_TARGET` 指定已有别名。原工作根由用户的私密会话上下文或 `DRILLDOWN_REMOTE_ROOT` 提供，不能从任意目录猜测。

1. 核对云端 Tailscale 状态和 `ssh -o BatchMode=yes -o ConnectTimeout=20 win-tailnet` 的真实连接结果；沿用已有主机密钥验证，不关闭验证。
2. 远程确认身份、指定目录和 Python 解释器存在。Windows 默认 shell 可能为 cmd；涉及中文/空格路径时使用正确引用的 PowerShell，或 UTF-16LE `-EncodedCommand`，不要拼接未转义的路径。
3. 读取下列相对原工作根的入口。读取最新进度、接受状态和必要依赖，不先重读所有历史正文。
4. 在原工作树的 `research/cloud_handoff_20260928/` 中创建真实接手回执：UTC 时间、会话/提交身份、实际读取文件的 SHA256、最新正式日期、待办、连接与写回是否成功。读写失败要照实记录。
5. 只有本机出现可复核的回执，才能在 Git 写“已接手”。不要把本地助手的准备记录当作云端已执行。
